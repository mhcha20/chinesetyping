# 速成打字班

互動式倉頡／速成中文輸入法教學：認識字根、拆字、速成取頭尾、60 秒挑戰，以及 1200 常用字庫特訓。
直接打開 `index.html` 就可以玩（用實體鍵盤效果最好）。

## 資料來源
- 倉頡碼：[rime/rime-cangjie](https://github.com/rime/rime-cangjie)（倉頡五代，LGPL）
- 字頻排序：[rime/rime-essay](https://github.com/rime/rime-essay)，另外手動加入 22 個常用粵語字（係、唔、嘅、咗、冇⋯）
- 速成碼 = 倉頡碼第一碼＋最後一碼；單鍵碼字（如「日」）已排除
